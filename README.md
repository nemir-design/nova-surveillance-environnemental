# nova-surveillance-environnemental
tableau de bords de surveillance environnemental pour autorités
The problem

In Bukavu (South Kivu, DR Congo), poor waste management and public insalubrity increase rain-related risks: waste clusters can block water channels. Satellite data exists, but it is complex and hard for local authorities and community organizations to use.

The solution

NOVA is an environmental monitoring platform that brings rainfall, risks and alerts together on a single map, then turns them into documents useful for decisions. It converts complex satellite data into simple information, so people can act quickly.

Key figures

332 waste clusters detected
27 block a water channel
5 NASA products combined
Features
Clear alerts: a green, yellow, orange or red level shows whether water is a threat. Thresholds can be adjusted per neighborhood.
Readable map: each cluster is located with its commune, elevation and runoff risk.
No code required: readable tables for the city hall and associations, with no raw files.
Action priorities: the places to treat first, before the next rain.
Scalable: designed for Bukavu, ready to extend to other cities and predictive analyses.
Decision-support documents

Before each meeting with decision-makers, three documents are generated from the platform data:

Summary note: the day's alert level, most exposed areas, population concerned.
Intervention priorities: neighborhoods ranked by risk level, access and resources needed, recommended time frame.
Recommendations: immediate measures, alert messages to residents, follow-up after the event.
